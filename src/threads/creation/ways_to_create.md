## Java Thread Creation Methods

| Method              | Use case                         |
|---------------------|----------------------------------|
| `Thread` class      | Learning / simple cases          |
| `Runnable`          | Standard basic approach          |
| Lambda Runnable     | Cleaner syntax                   |
| `ExecutorService`   | Production systems (recommended) |
| `Callable`          | When you need return value       |
| `CompletableFuture` | Async pipelines                  |
